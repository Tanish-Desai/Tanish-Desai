# Hey, I'm Tanish 👋

CS student at VIT Chennai. I spend most of my time on LLM/RAG security research and full-stack builds, and the rest of it tinkering — embedded boards, my own PC, and the occasional game in Godot.

---

### On the research side

I work on making RAG pipelines harder to break — adversarial benchmarking, retrieval attacks and defenses, that kind of thing. Currently co-authoring work under review at a couple of journals. I'm generally into agentic AI and applied ML/LLM engineering — less interested in theory for its own sake, more in what actually holds up in production.

### Outside of that

Embedded electronics started as a hobby and never really stopped — I like building small things that talk to hardware (ESP32s mostly). I also can't leave my own PC alone; if something's running hot or the BIOS fan curve is being dumb, I'll write a script to fix it myself. And every now and then I build a little game in Godot (know my way around Unity too).

### A few things I've built

- **[secure-rag-harness](https://github.com/Tanish-Desai/secure-rag-harness)** — Dockerized setup for running and evaluating adversarial attacks against RAG pipelines, with hybrid dense + BM25 retrieval on Postgres/pgvector
- **[Esp32LoadBal](https://github.com/Tanish-Desai/Esp32LoadBal)** — A Wi-Fi reverse proxy on an ESP32 that learns to route traffic with Q-learning instead of plain round-robin — cut latency by ~22%
- **[Auto-Socket](https://github.com/Tanish-Desai/Auto-Socket)** — Control home devices with hand gestures, using OpenCV/MediaPipe on the vision side and an ESP32 on the hardware side
- **[Omen-XD-Fan-Control](https://github.com/Tanish-Desai/Omen-XD-Fan-Control)** — Because my laptop's stock fan curve wasn't cutting it
- **[better-compiler](https://github.com/Tanish-Desai/better-compiler)** — A compiler project I built to actually understand how compilers work under the hood
- **[portfolio](https://github.com/Tanish-Desai/portfolio)** — My personal site, also linked below
